# 顺丰官网 Web 自动化测试项目

基于 Selenium + Java 的顺丰官网（www.sf-express.com）自动化测试项目，包含自动化测试脚本和对应的测试用例文档，用于验证顺丰官网核心业务流程的正确性。

## 技术栈

| 类别 | 技术 |
|------|------|
| 编程语言 | Java |
| 自动化框架 | Selenium WebDriver |
| 测试框架 | 【JUnit】 |
| 构建工具 | 【Maven 】 |
| 浏览器驱动 | ChromeDriver  |
| 用例文档 | Excel（.xlsx） |

## 运行方式

### 前置环境
- JDK 8 及以上
- 已安装对应版本的浏览器及驱动（ChromeDriver 需与浏览器版本匹配）
- 如用 Maven

### 运行步骤
```bash
# 1. 配置好 JDK 和浏览器驱动环境变量
# 2. 直接运行 TestSF.java 主类
# 或（如用 Maven）：
mvn test
```
